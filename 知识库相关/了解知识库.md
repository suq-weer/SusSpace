# 了解知识库

## 在这之前：仓库创建者的一点话语

*SusSpace*，**这才是我要的文档站**。

我，也就是这个知识库的仓库创建者——Xiaosu，终于找到了让自己心满意足的地方。

我之前有通过 *nginx* 虚拟主机架设 *typecho* 环境来搭建一个属于自己的个人博客，博客主题都是自己用手机的 *Spark Editor+Termux* 一步步搭建的，也在那里上传过很多文章。热门的 *WordPress* 太过烦杂，支持 *php* 且简约的博客后端除了 *typecho* 好像就没多少了。

直到我碰到了 *Vitepress*……

我知道，*typecho* 和 *Vitepress* 走的是完全不同的两个道路，一个是**服务端动态渲染网页**，一个是**纯客户端静态渲染网页**，但 *typecho* 编辑器功能很少，导致它更新很麻烦，反而 *Vitepress* 根本就没有编辑器，所以就“没有麻烦一说”。（好像也挺好的？）

但却在我一番查找过后，让我找到了一个比 *Typecho* 更方便的 *Vitepress* 更新方案——*GitHub Pages 部署 + Obsidian 编辑器*。

*Obsidian* 是我一直在用的编辑器，**功能丰富插件多**，**十分方便还有手机版**，一般我写稿的时候都在用这个写，能用现有的工具真的是太好了！

同时**我又想让网站不仅仅局限于我自己的博客**，也**想要为自己制作的模组搞个发布页**之类的，更想搭一个所有人都可以投稿的“**文档站**”而不是个人网页。<small><del>（这样我就能名正言顺地用 GitHub Pages 啦！）</del></small>

于是便使用了 *GitHub Page* 来作为 *SusSpace* 的后端。

所以，虽然我不知道会不会有人想要参与贡献这个文档站，如何参与贡献的具体步骤我还没搞好。

**但我希望**，**我**，**还有大家都可以像文档站的口号一样**：**“知识共享，一起进步！”**
