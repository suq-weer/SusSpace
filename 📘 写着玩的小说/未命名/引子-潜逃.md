# 引子  潜逃

企业霸权城市，全球最大机电制造公司凯尔特是这里的霸主。

他们修筑了一座“世界之巅”——莱德之塔。

而在塔下，从塔顶上看不过是一两个“像素”的小巷子里，男人踩着泥坑，不管不顾地朝前方的路奔去。在他背后，是公司的跟踪无人机，那无人机在用灯光不断地闪烁并照向男人。

天空下起了小雨，很阴，很暗，巷子里只有几盏路灯照亮了周围的路，照明范围也小到几乎只能提供安慰作用。四周的花草随风摇摆，好似熬夜到神智不清在无规律地摇动。

男人并没有管那么多，耳边尽是他自己急促的脚步声，嘴里正在发出急促的呼吸声，他之所以跑得那么快，是因为他提着个类似手提箱的机器。

这机器让他兴奋不已，甚至都没有注意到衣服被不知是雨还是汗浸透了。

忽然男人停了下来，转过身去面向无人机群。

无人机群也停了下来一直面对着男人，下面的指示灯也不停地在闪烁。男人擦好身子，脱下了被泥沾湿的大衣，手提着手提箱却是一刻握着提箱的手却是一刻也没有松过。

又有一盏灯照了过来，越来越亮，又变成了好几盏灯照来照去。最后最亮的两盏车灯是排头的黑色电车。电车的车门在停稳了之后缓缓打开，里面走出来一位身材魁梧、头上戴着墨镜的男子，穿着黑大褂，好似黑帮的打手。

打手看向提着手提箱的男人，首先不是为他提着的东西生气，而是缓缓走过来对男人说：

“老同学，好久不见！今天你看起来又精神了一点呢！”

说完这句话时他停下了脚步，打手身后另外几盏灯光也跟了过来，这才看清原来是一整排的战术手电，那些些枪也统一是满改的高射速型 M4A1。

“今天兄弟的排场可是真够大啊！可惜我也没有多少时间和你们扯皮了！”

男人说完从口袋里掏出拿出了枪，上膛指向了打手。士兵们也都将子弹上膛并将枪口对准男人。

男人拿着枪说：“宴会上的灯是不是太亮了？”
